# PRAGVI

Premium creative marketplace for AI dance videos, images, prompts, and digital creator assets.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons
- Supabase Auth + Postgres
- Razorpay Checkout

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build
- `npm run lint` — ESLint

## Notes

- AI Tools catalog is excluded from the first KYC release package.
- Homepage CMS remote publish is gated by `HOMEPAGE_REMOTE_PUBLISH` (default off).
